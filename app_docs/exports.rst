Exports
=======

The app includes downloads for records, tables, figures, and packaged
reference-data subsets.

Data Downloads
--------------

Processed and filtered records can be downloaded as CSV. Labelled summary
tables include their own CSV download buttons; each table download contains
only the table currently displayed.

ASHRAE Subset ZIP
-----------------

When using the packaged ASHRAE DB II data, the app can export selected
countries or filtered subsets as a ZIP package containing:

- CSV data,
- attribution text,
- manifest metadata.

Figure Downloads
----------------

Figures can be downloaded as:

- PNG,
- SVG,
- PDF.

The export controls include size, quality, and padding options so that plot
titles, axis labels, legends, and data marks have room in the output file.
Vector formats such as SVG and PDF are preferred for manuscripts when the
journal workflow supports them.
