References
==========

Primary DC3 Paper
-----------------

Duke, O.P., Kowli, A., and Zhou, J. (2026). "Development of a D-centred
thermal comfort classification model based on the ASHRAE global thermal
comfort database II: an Indian case study." *Building and Environment*,
293, 114324. https://doi.org/10.1016/j.buildenv.2026.114324

How This Reference Is Used
--------------------------

The deterministic OC rule, DC3 letter mapping, suffix convention, numeric
encoding, and Z-class interpretation implemented in DC3 Model are based on
Duke et al. (2026). Where this documentation describes the DC3 model rules, it
is referring to Duke et al. (2026) unless otherwise stated.

ASHRAE Global Thermal Comfort Database II
-----------------------------------------

Parkinson, T., Tartarini, F., Földváry Ličina, V., and contributors (2022).
"ASHRAE global database of thermal comfort field measurements" [Dataset].
Dryad. https://doi.org/10.6078/D1F671

Földváry Ličina, V., Cheung, T., Zhang, H., de Dear, R., Parkinson, T.,
Arens, E., Chun, C., Schiavon, S., Luo, M., Brager, G., Li, P., and
co-authors (2018). "Development of the ASHRAE Global Thermal Comfort Database
II." *Building and Environment*, 142, 502-512.
https://doi.org/10.1016/j.buildenv.2018.06.022

DC3 Model uses ASHRAE DB II only as a packaged reference dataset and app demo
dataset. The dataset source is credited in the package, in exported ZIP
archives, and in this documentation. The original Dryad record describes the
database as an open-source research database for thermal comfort field
settings, and the Földváry Ličina et al. (2018) paper describes the database
development, scope, and web-based filtering/visualisation goals.
